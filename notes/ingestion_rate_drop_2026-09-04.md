### 원인 2 (부차, 실재 버그지만 신규 인입 영향 작음) — petlabel df -BG macOS 파싱
`com.rianileo.petlabel-backlog` exit code 3. `scripts/petlabels_chunked.sh:44-45`가 free-GB를
`df -BG`(리눅스 플래그)로 파싱 → macOS에선 빈값 → `free_gb=0 < 3` → false "disk full, abort".
실제 디스크 24GB 여유. (line 40-42 주석은 반대방향 리눅스 버그 픽스 흔적 — 고치며 macOS를 깸.)

**수정 방향:** OS 감지 후 macOS는 `df -g`(GB) 또는 양쪽 동작하는 `df -k / | awk 'END{print int($4/1048576)}'`
로 교체. 단 이 잡은 백필 소진 완료라 급하지 않고 **신규 footage 인입엔 무관**.
