# 설계문서 — 레퍼런스-구동 MV 편집 아키텍처 (2026-11-26)

> **목적:** MV의 **편집**(컷이 언제 연결되고 언제 하드컷되는지·샷사이즈 진행·케이던스)과 **미감**(색/조명/질감)을
> **여러 레퍼런스 MV의 진짜 프레임단위 분석**에서 뽑은 **생산 제약**으로 구동한다. per-cut 독립 생성이 만드는
> "연결성 없음·줌 톱니·전부 미디엄·단조" 를 근본 해결하되 — **완전 복제는 금지**(레퍼는 문법·조명·앵글 ref일 뿐,
> 콘텐츠·피사체·세계는 우리 것). 이 문서로 **프로토타입**을 돌린다.

## 0. 왜 (근본, 네온 미드나잇 크루즈 최종본 피드백에서 확정)
PD 피드백(16-18s 댄스 비트X·27s 위글 불필요·33-40s·1:05+ 줌 톱니·50-52s 좋은 와이드 너무 짧음·1:01 댄스 짧음·
**"연결성 없어, 드라이브인데"**)을 근본으로 접으면:
- **메타근본 = per-cut 독립 생성** — 컷마다 자기 스틸(리셋 프레이밍)+자기 i2v(자기 push-in). 공유 카메라 궤적 없음.
- **R1 연결성/줌 톱니** — 매 컷 리셋+줌. 드라이브(연속)를 구조적으로 못 만든다.
- **R2 샷사이즈 미실현** — Director가 WS/CU 지정해도 gpt-image가 전부 미디엄(캐노니컬 레퍼가 미디엄 bias) → 리셋이 늘 같은 구도.
- **R3 댄스 비트맹 + 짧음** — i2v가 노래 비트 모름 + 그루브 컷이 2-4초.

★**그러나 per-cut은 못 고치는 게 아니다**(PD 교정): **전체를 아우르는 Director가 박찬욱 콘티처럼** 컷 간 연결/하드컷을
설계해 떨구면 per-cut으로도 된다. 그리고 **모든 씬이 연속이면 안 된다** — 연결 vs 하드컷의 **리듬이 곧 레퍼런스의 편집 문법**.
그래서 레퍼런스를 **프레임단위로** 분석해야 한다(미감만이 아니라 **편집 구조**를 뽑으려고).

## 1. 핵심 원칙 (제약)
1. **여러 레퍼런스** — 1개가 아니라 **N개(≥3)** 를 분석. 편집 문법 + 미감 둘 다. 한 곡/컨셉에 맞는 레퍼 군(citypop 나이트드라이브면 그 류 여러 편)을 모아 **합성**한다.
2. **진짜 분석한 것만** — 모든 제약은 **실제 프레임단위 분석(`agents/mv_ref_director`)의 출력**에 근거. "분석한 척/가정" 금지. 문서·코드가 **무엇이 실제 분석됐고 무엇이 미분석인지 명시**(§6 상태표).
3. **분석 → 생산 제약**(YDKMN §4.6 교훈) — 분석은 노트가 아니라 **컷별 제약**이 된다: 샷사이즈 시퀀스·연결/하드컷 플래그·케이던스·카메라무브. 안 옮기면 "전부 정면 미디엄"으로 PD가 "한땀한땀 봤냐" 잡는다.
4. **완전 복제 금지**(YDKMN + PD "완전 똑같은건 안돼") — 레퍼는 **편집 문법·조명·앵글·미감의 영감**일 뿐. **콘텐츠/피사체/세계는 우리 것**(펫=실제 동물·우리 웜 톤·우리 가사/스토리). 레퍼의 사람 프레임을 bg로 깔지 마라(의인화+톤 드리프트). 여러 레퍼를 합성해 **우리 것**을 만들지, 한 편을 클론하지 않는다.
5. **연속성은 선택적** — 레퍼 문법이 **연결**(샷 내 push·측면 트래킹 홀드)인 구간은 연결, **하드컷**(새 앵글/인서트/다른 씬)인 구간은 끊음. 모두 연속 X, 모두 리셋 X.

## 2. 데이터 모델 — "편집 문법 템플릿"
`agents/mv_ref_director.analyze_reference`가 레퍼당 내는 것(이미 구현·실제 검증된 스키마):
`shots[]{start,end,shot_size,camera_move,subject_framing,color_palette,lighting,transition_in,technique}` + `directing_standard{palette,signature_shots,camera,cut_cadence,lighting,texture,mood}`.

★여기서 **편집 문법**으로 쓸 필드: `shot_size`(진행)·`transition_in`(하드컷/디졸브/매치컷 = 연결 vs 끊김)·`camera_move`·컷 길이(=케이던스). N개 레퍼를 분석해:
- **grammar profile** = 샷사이즈 전이 분포(예: CU→CU 홀드율, WS 빈도)·하드컷 vs 연속-카메라 비율·중앙값 컷 길이·섹션별(인트로/벌스/훅) 리듬.
- **aesthetic profile** = 팔레트·조명·텍스처·bloom/그레인(여러 레퍼 합성, 우리 네온블루 톤으로 recolor).
둘을 합쳐 **`edit_template`**(JSON): 섹션별 샷 시퀀스 레시피 + 연결/하드컷 리듬 + 케이던스 + 미감.

## 3. 파이프라인 변경 (설계)
1. **stage_reference 확장** — 한 편이 아니라 **N개 레퍼**를 fetch+프레임분석 → `edit_template` 합성(미감+문법). (현재는 1편 homage만.)
2. **Director = 콘티 Director(overarching)** — 가사/컨셉 컷을 **`edit_template`에 매핑**: 섹션별로 레퍼 샷사이즈 진행·연결/하드컷 패턴·케이던스를 따라 **컷마다** {shot_size(강제)·continuity[연결|하드컷|scene_break]·camera_move} 지정. 전체 시퀀스를 보고 떨군다(독립 X).
3. **스틸 생성 = 샷사이즈 실현**(생산 제약) — `build_prompt`가 shot_size를 **프레이밍으로 강제**(ECU=눈 꽉참·CU=얼굴·WS=차 작게). 캐노니컬 레퍼의 미디엄 bias를 shot_size가 이긴다.
4. **연속 실행** — `continuity=연결` 구간: **interp 모드**(컷 N 첫프레임=컷 N-1 끝프레임, ★우리 이미 있음)로 매끄럽게. `하드컷`: 독립 i2v. `scene_break`: **캐노니컬 재앵커**(star-shaped, drift 방지). 카메라무브가 궤적을 이어감(리셋 push-in 금지).
5. **히어로/댄스** — 시그니처/와이드/댄스 컷은 **길게 홀드**. 댄스는 억지 비트맹 i2v 대신 자연모션 + (옵션)어셈블 비트싱크.
6. **일관성**(별개 축, 이미 MV판 배선) — 캐노니컬 레퍼런스 뱅크(펫+차+장소)로 cross-scene drift 방지. (회고 §4.13·핸드오프 av_consistency.)

## 4. 프로토타입 (이 설계 검증)
1. **N(=3) 레퍼 선정·실제 프레임분석** — citypop 나이트드라이브 류 3편(예: Blinding Lights + 2편 더). `mv_ref_director`로 **진짜** shot-by-shot. (★미분석을 분석한 척 금지.)
2. `edit_template` 합성(문법+미감).
3. **드라이브 한 구간(mv04 30~45초, 가사 2-3줄)** 을 `edit_template`로 콘티 → shot_size 강제 스틸 → interp-chain(연결)/하드컷 → 조립.
4. **검증**: 연결 vs 하드컷 리듬이 레퍼처럼 나오나·샷사이즈 다양·줌 톱니 사라짐·미감·**완전 복제 아님**(우리 펫/톤/가사).

## 5. 성공 기준
- 연속 드라이브가 **연결**로 흐르고, 의도한 지점만 **하드컷**(레퍼 리듬).
- 한 섹션 안 **WS/MS/CU/ECU/인서트 실제로 다양**(전부 미디엄 아님).
- 줌 톱니 소멸. 히어로/와이드 샷 적절히 **길게**.
- 미감이 **여러 레퍼 합성**(한 편 클론 아님)·우리 네온 톤.
- cross-scene 차/펫 **drift 없음**(캐노니컬).

## 6. 상태 — 진짜 분석한 것 vs 미분석 (정직)
- ✅ **실제 분석됨**: Blinding Lights **151샷** 프레임분석(`data/tmp/mv/mv04/ref/shots.json`, `mv_ref_director` 실제 실행). shot_size·camera_move·transition_in·palette 등 실측.
- ❌ **아직 안 됨**(설계만): ②다른 레퍼 ≥2편 프레임분석 ③`edit_template` 합성 코드 ④stage_reference N-레퍼 확장 ⑤콘티 Director(edit_template 매핑) ⑥build_prompt shot_size 강제 ⑦interp-chain 연속 실행 배선 ⑧프로토타입 구간.
- → 프로토타입은 **②부터 진짜로** 시작(레퍼 2편 더 실제 분석). 이 문서의 어떤 수치/문법도 아직 1편(Blinding Lights)에서만 나온 것 — N편 합성 전엔 단정 금지.
