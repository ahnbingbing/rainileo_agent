# MV 에이전트 — PD 피드백 원장 (feedback ledger)

> **목적.** 오리지널 MV를 만드는 동안 PD가 주는 피드백·판단·취향을 **스테이지별로** 모은다.
> 이 원장이 나중에 **MV 자동생성 에이전트**(`[[mv-agent-spec]]`)의 각 스테이지 프롬프트로
> 흡수된다 — 즉 여기 쌓인 한 줄 한 줄이 에이전트가 "PD처럼 판단"하게 만드는 학습 소스다.
>
> **쓰는 법.** 곡/MV를 만들다 PD가 뭔가 지적하거나 선택하면, 날짜 대신 **원칙(principle)**으로
> 적는다 — "무엇을 / 왜 / 어떻게 적용"의 3요소. 같은 결의 피드백은 기존 항목을 **발전**시키되
> append-dated 금지(git이 provenance를 가짐). 애매하면 아래 스테이지 중 어디에 속하는지 먼저 판단.
>
> **스테이지 = 에이전트 파이프라인** (`[[mv-agent-spec]]`):
> 주제/스토리 → 곡(가사+Suno) → 레퍼런스 디렉팅 분석 → MV Writer/Director(컷) → 렌더 → make_mv → 검수.

---

## 0. 메타 — "내가 했던 방식을 따라해라"
- 에이전트 행동 사양 = **이 세션들의 반복 디렉팅+픽스 루프 전체**. 결함→재렌더 루프도 PD식.
- 선택이 애매하면 **PD pick**으로 후보 제시(리안나2·nmixx2 선택처럼). 혼자 확정 금지.

## 1. 주제/스토리 에이전트
- 주제는 **함미하비 스토리(pd_notes)+캐릭터 지식**에서 발굴. 실제 사건 = 저작권0 + 진정성.
- 우선순위(2026-10-30): ①같이 자는 유대(완료) ②엄마 기다리기 ③할로윈(타임리) ④소파 사수 전쟁.
- 장르 레인을 주제가 결정: **잔잔/유대/기다림 = 발라드·미드(실사/RF 룩)**, **놀이/파티/티격 = 댄스·힙합(밈 AV)**.

## 2. 곡 에이전트 (가사 → Suno)
- **여성 보컬 = 청아·맑음**(보아 느낌). 프롬프트는 품질어로: "clear pure elegant female vocal,
  bright clean controlled tone". `--vocal-gender f`. (아티스트명은 Suno 모더레이션.)
- **간결하게**: ~70s, short 4s intro, 1절(verse+chorus+outro), continuous, **NO long instrumental
  breaks**, vocals throughout. 가사도 1절로 축약. (길면 스플라이스·정렬 다 깨짐.)
- **여러 스타일 버전 비교**(스타일 2~3종 × all-clips variant) → PD pick.
- **"간결"의 하한 주의** — 밈/업템포는 너무 짧으면(≲20s) 뒤가 잘린 느낌·훅 반복 부족("뒤가 너무
  짧아"). 밈/업템포 목표 **~40s+**: verse + 후렴 2회 + 아웃트로 훅 반복, 급히 끊기지 말고 완결.
  (발라드는 ~40~50s로도 충분.) 짧게 안 나오면 **가사에 후렴·아웃트로 반복을 넣어** 부를 양을 늘린다.
- **PD pick 취향 신호(2026-11-01 새 주제 3곡)**: 엄마=따뜻한 어쿠스틱 K-인디(피아노+스트링 발라드보다
  선호), 할로윈=버블리 할로윈 댄스팝(쎄한 일렉트로팝보다), 소파=통통 K-pop 밈(펑키 시티팝보다). →
  밝고 통통·따뜻·청아 쪽이 과한 시네마틱/쎄한 쪽보다 채널 톤에 맞음.
- 가사는 **의성어/의태어**를 넣어라 — Director가 그걸 동작 컷으로 살린다("톡톡톡/폴짝/딸깍").
- 가사 **각 줄의 주인공을 명확히**(까만 랴니 / 레오 / 둘이·나란히) — 서브젝트 매칭의 기준이 됨.

## 3. 레퍼런스 디렉팅 분석
- 컨셉 → 적합 레퍼런스 유튜브 검색 → yt-dlp+Gemini로 분석(배경색전환/프레이밍/모티프/컷리듬/후렴안무)
  → 그 브리프로 컷 시나리오. (Twista "Give It Up" dmDOqDsxUSY = 첫 성공.)

## 4. MV Writer/Director (컷 시나리오)
- **가사 집중 · 컷 수 늘려 타이트 매핑**(균등분배 금지, 비트별 전용 컷).
- **서브젝트 매칭**: 가사 줄 주인공 = 화면 펫. "등에 기대/올라타"=레오가 랴니 등 위 실제 클립.
  실사는 서브젝트별 키잉(ry/leo/onback/naranhi/together)해 라이브러리化 후 줄마다 매칭.
  VLM 라벨 불신, 프레임으로 확인(08_16은 "랴니" 태그인데 실제 레오였음).
- **색 다양성** — 같은 색 반복 금지(핑크 그만). 샷마다 색 전환.
- **밝기** — PD는 어둡고 무드 있는 톤 선호. 톤맵 과밝음 금지.
- **Seedance 구도 함정**: "둘이 무대 정면/바우" = 밴드멤버(다수 동물) 추가·펫 작아짐. 안전 =
  솔로 번갈아(랴니 보컬/레오 기타) + "한쪽 마이크·한쪽 기타 나란히". 바우=솔로 or 나란히.
- **발라드 하이브리드**: AV 연주 장면 배경 루프 + 실사 낮잠/일상 인서트 = "펫이 자기 이야기를 노래로".
- **타임리 주제는 실사+AV 혼합**(PD 2026-11-01 할로윈): 쓸 만한 실제 시즌 실사(할로윈 코스튬 클립 등)가
  있으면 AV 스타일 컷과 **섞어라** — 실사로 진정성/타임리함, AV로 훅·스펙터클. 밈 AV라고 100% AV 아님.
  주제가 실제 이벤트(할로윈·명절)면 라이브러리에서 해당 실사부터 찾고 컷 시나리오에 인서트로 배치.

## 5. 렌더 / make_mv
- Seedance는 **FAST 모델**(프로덕션 동일, standard 2배 느림).
- **SDR 클립이 다크그레이딩 우회** = "아직도 밝아"의 진짜 원인. color_transfer 확인, SDR→HLG swap.
- 크레딧 = **작곡 라레수 · 작사 함미하비**. 타이틀 = 뮤비 카드(핑크 키커+악센트).
- **원곡 > 트림/스플라이스/재생성**("길면 뭐 어때"). 끝 안 얼림·노래 풀재생+여운 페이드.
- **자막 = 보컬 타임 싱크**(카라오케, 컷 길이에 묶지 말 것). 긴 곡 align은 반 청크. `[[mv-caption-sync]]`

## 6. 검수 에이전트 — "이게 검수 통과한거라고?"
- **스팟체크 금지. 전달 전 전체 컷 컨택트시트**(~6s 간격)로 모든 컷 확인:
  ①펫이 실제 보이는가(담요속/솔로=안보임) ②서브젝트 정확("레오만 나와야") ③AV 결함(다수동물/기타
  작아짐/꼬리) ④바우·인사=맨 마지막 컷 ⑤실사 채도 자연 ⑥끝 안 얼림·노래 풀재생.
- Gemini(video_actions both-visible 구간·align_audio)로 자동 검증. `[[mv-pipeline-and-action-layer]]`
- **캐릭터 fidelity**: 랴니 무꼬리(플레이바우가 꼬리 재생성 유발), 흰 턱/가슴/발 마킹 보존.

## 7. 버전 관리
- **버전은 항상 별도 파일명**(무의상/의상, A2/C2 등 섞지 말 것).
